# Portfólio Pessoal

Site pessoal com apresentação profissional, conhecimentos técnicos e projetos.

🔗 **Acesse online:** https://portfolio-eduardonunes.netlify.app

## Conteúdo do site
- Apresentação e biografia
- Conhecimentos técnicos
- Projetos desenvolvidos
- Informações de contato

## Tecnologias
HTML5 · CSS3 · JavaScript · Netlify (hospedagem)

## Como executar localmente
1. Clone o repositório
   ```bash
   git clone https://github.com/SEU-USUARIO/portfolio.git
   cd portfolio
   ```
2. Abra o arquivo `index.html` no navegador
   (ou use a extensão Live Server do VS Code)

## Aprendizados
- Estruturação e estilização de páginas com HTML e CSS
- Interatividade com JavaScript
- Publicação de um site com deploy no Netlify
